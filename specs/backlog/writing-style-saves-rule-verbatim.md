# Backlog: writing-style-saves-rule-verbatim

## What

When the person teaches a rule ("new rule: ..."), writing-style saves it
to persona memory exactly as said, adding nothing of its own.

## Why

In a real-model Macro run the reflector found the agent had added a
clause the person never said to a saved rule. A saved rule later moves
into the skill's text, so an addition there becomes the skill's.

## Open questions

- Is a skill instruction enough, or should the core compare the saved
  text with the person's words at close?
